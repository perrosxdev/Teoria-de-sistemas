# 🔧 Requisitos Mínimos del Modelo

[← Volver al README principal](../README.md)

---

## Complejidad Mínima

El modelo deberá tener una complejidad mínima que permita aplicar adecuadamente los conceptos de dinámica de sistemas. Para ello, el sistema seleccionado deberá considerar **al menos dos subsistemas**.

Un subsistema corresponde a una parte del sistema general que agrupa variables relacionadas entre sí.

### Ejemplos de subsistemas

| Problema | Subsistema 1 | Subsistema 2 |
|----------|-------------|-------------|
| Sobrepoblación animal | Población de animales | Recursos del ecosistema |
| Propagación de enfermedad | Población | Mecanismos de control o recuperación |
| Problema informático | Demanda de usuarios | Infraestructura tecnológica |

---

## Variables del Sistema

El modelo deberá considerar un **mínimo de diez variables**. Estas variables deberán permitir representar el problema seleccionado y explicar su comportamiento en el tiempo.

---

## Componentes Mínimos Obligatorios

| Componente | Cantidad mínima |
|-----------|----------------|
| Stocks o niveles | 2 |
| Flujos | 2 |
| Variables auxiliares o parámetros | 2 |
| Bucles de retroalimentación | 1 |

---

## Definición de Variables

Cada variable deberá estar claramente definida, indicando:

- ✅ Su **función** dentro del modelo
- ✅ Su **unidad de medida**
- ✅ La **fuente de información** utilizada

> ⚠️ En caso de utilizar supuestos, estos deberán estar **justificados de forma explícita**.
