# 📄 Estructura Mínima del Informe

[← Volver al README principal](../README.md)

---

El informe deberá contener, como mínimo, las siguientes secciones:

| N° | Sección |
|----|---------|
| 1 | Portada |
| 2 | Resumen |
| 3 | Introducción |
| 4 | Definiciones y marco teórico |
| 5 | Definición del problema |
| 6 | Identificación de subsistemas |
| 7 | Identificación de variables del sistema |
| 8 | Influencias de primer, segundo y tercer orden |
| 9 | Diagrama causal |
| 10 | Identificación de bucles de retroalimentación |
| 11 | Datos históricos, unidades de medida y supuestos del modelo |
| 12 | Diagrama de Forrester |
| 13 | Construcción del modelo |
| 14 | Simulación del escenario base |
| 15 | Propuesta de intervención o estrategia de mejora |
| 16 | Simulación del escenario de mejora |
| 17 | Resultados |
| 18 | Conclusiones |
| 19 | Referencias bibliográficas en formato APA 7 |

---

> 📝 Recuerda que el informe debe ser elaborado en **LaTeX** (`article`, fuente Palatino, tamaño 10) y entregado en formato **PDF**.
>
> Ver detalles de formato en [Grupos de trabajo y entrega](./grupos-y-entrega.md).
