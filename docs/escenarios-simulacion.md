---

El modelo deberá permitir comparar **al menos dos escenarios**.

---

## Escenario Base

Corresponde al comportamiento del sistema **sin intervención**. Refleja la situación actual o de referencia del problema modelado.

---

## Escenario de Mejora

El grupo deberá modificar una o más variables del modelo para analizar cómo cambia el comportamiento del sistema.

> ⚠️ La propuesta de intervención **no debe entenderse como una política pública**. Puede ser una acción, estrategia, mejora técnica, cambio organizacional, medida de control o ajuste dentro del sistema modelado.

### Ejemplos de intervenciones

| Tipo de modelo | Posibles intervenciones |
|---------------|------------------------|
| Propagación de enfermedades | Reducir tasa de contacto, aumentar tasa de vacunación, mejorar tasa de recuperación |
| Sobrepoblación de animales | Controlar tasa de reproducción, modificar disponibilidad de recursos |
| Modelo informático | Aumentar capacidad de servidores, incorporar balanceo de carga, optimizar procesamiento, mejorar ciberseguridad |

---

## Objetivo de la Comparación

La comparación entre escenarios debe permitir explicar si la intervención propuesta:

- 📈 **Mejora** el comportamiento problemático
- ⚖️ **Estabiliza** el sistema
- 📉 **Reduce** el efecto no deseado
- 🔄 **Transforma** la dinámica del sistema
